01 // QUICK START

Quick start in 4 steps

  1. Get a wallet. For Solana: Phantom, Solflare or Backpack. For Robinhood Chain, Base or BSC: MetaMask, Rabby, Coinbase Wallet or any EVM wallet.
  2. Copy the official CA from the CA box on the home page. Each address has its network logo next to it.
  3. Connect your wallet with the Connect button. Pick a network, pick a wallet, approve the connection.
  4. Open your patient file in the Patient Record section to see your $WLX balance and clearance.
02 // AUTH

Wallet login

Login is read-only. The site asks your wallet for your public address only. It never requests token approvals, signatures for transfers, or any payment.

EVM networks (Robinhood Chain, Base, BSC)

  • The site detects every installed wallet (EIP-6963). If several are installed, you choose which one to use.
  • After connecting, the wallet is asked to switch to the selected network. If the network is missing, it is added automatically with the official RPC and explorer.
  • If you switch networks inside your wallet later, the site follows.

Solana

  • Supported: Phantom, Solflare, Backpack. Wallets that are not installed show a download link.

Disconnecting

Click your address in the header → Disconnect. The site forgets the session. You can also revoke the site in your wallet's "connected sites" settings.

03 // CONTRACT

Official contract address

Always copy the CA from this website or the official X account. The Copy CA button copies the full address. The arrow icons open the token page on each network's explorer so you can verify it.

If the box says Awaiting deployment, the token has not launched yet. Anything you see elsewhere is not official.

04 // WARDS

Networks

Single vs multi mode

  • Single mode — the site shows one network only and the whole interface adopts that network's colors and identity.
  • Multi mode — the site always shows all four wards: Solana, Robinhood Chain, Base and BSC. Robinhood, Base and BSC share the same EVM contract address; Solana has its own mint address.
05 // ACQUIRE

Getting $WLX

  1. Fund your wallet with the network's gas token (SOL on Solana, ETH on Robinhood Chain and Base, BNB on BSC).
  2. Open a decentralised exchange you trust that supports that network.
  3. Paste the official CA from this site into the token search. Never pick a token by name or logo alone — copycats use both.
  4. Check the contract on the explorer link from the CA box before you confirm any swap.
The WELIX team never DMs first, never asks for your seed phrase and never asks you to "validate" or "sync" a wallet.
06 // CLEARANCE

Clearance levels

When you connect, the terminal reads your real on-chain $WLX balance on the selected network and assigns the highest level you qualify for.

08 // SAFETY

Safety protocol

  • Bookmark the official site and only open it from your bookmark.
  • Verify the CA on the explorer — the network logo in the CA box tells you which chain it belongs to.
  • Never share your seed phrase or private key. No real support agent will ever ask for it.
  • Connecting to this site is read-only. If any page asks you to approve spending to "claim" WELIX, it is a scam.
  • Crypto is volatile. Only use money you can afford to lose.
